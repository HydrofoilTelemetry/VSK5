# Hydrofoil Telemetry / VSK5

**Applications, utilities, and custom boat models built for Virtual Skipper 5 (VSK5).**

A collection of independently developed tools, enhancements, and custom sailing models designed to expand the Virtual Skipper 5 experience.

### Projects & Features

- **VSK5 Applications:** Custom Windows applications for race management, navigation, and game-related utilities.
- **Racecourse Mapping:** Interactive maps featuring course objects, distance measurement, zoom, and rotation.
- **Live Telemetry:** Development of real-time multiplayer boat tracking, position monitoring, and breadcrumb trails.
- **Race Results & Scoring:** Utilities for processing race results, managing regattas, and calculating standings.
- **Custom Boat Models:** Original sailing models, including the HTX60 offshore foiling monohull, with custom sails, hull designs, and racing skins.
- **Additional Utilities:** Tools and enhancements developed specifically for the VSK5 community.

### About

An independent development project dedicated to bringing new boats, modern utilities, and additional functionality to Virtual Skipper 5.
